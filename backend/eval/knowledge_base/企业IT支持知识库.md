# 企业IT支持知识库

## 1. VPN连接配置指南

### 1.1 Windows系统VPN配置步骤

1. 打开"设置" → "网络和Internet" → "VPN"
2. 点击"添加VPN连接"
3. VPN提供商选择"Windows(内置)"
4. 连接名称输入：公司VPN
5. 服务器名称或地址：vpn.company.com
6. VPN类型选择：L2TP/IPsec与预共享密钥
7. 预共享密钥请联系IT部门获取
8. 登录信息类型选择：用户名和密码
9. 输入公司域账号和密码
10. 点击保存，然后点击连接

### 1.2 VPN常见问题

- **错误代码789**：L2TP连接失败，请检查预共享密钥是否正确，或在注册表中修改AssumeUDPEncapsulationContextOnSendRule为2
- **错误代码807**：网络连接被中断，请检查防火墙设置，确保UDP端口500和4500已开放
- **连接后无法访问内网**：请检查DNS设置，应使用公司内网DNS服务器10.0.0.1

### 1.3 VPN使用规范

- VPN连接时间限制：工作日8:00-22:00
- 禁止在VPN连接时访问非工作相关网站
- VPN密码每90天需更换一次
- 如连续3次输错密码，账号将被锁定30分钟

## 2. 打印机配置与故障排除

### 2.1 网络打印机安装

1. 打开"控制面板" → "设备和打印机" → "添加打印机"
2. 选择"添加网络、无线或Bluetooth打印机"
3. 等待搜索完成，选择目标打印机
4. 如果搜索不到，选择"我需要的打印机不在列表中"
5. 选择"使用TCP/IP地址或主机名添加打印机"
6. 设备类型选TCP/IP，主机名输入打印机IP地址
7. 等待驱动安装完成

### 2.2 各楼层打印机IP地址

| 楼层 | 打印机型号 | IP地址 |
|------|-----------|--------|
| 1F前台 | HP LaserJet Pro M404 | 192.168.1.101 |
| 2F研发部 | HP Color LaserJet Pro M454 | 192.168.1.201 |
| 3F市场部 | Canon imageCLASS MF445dw | 192.168.1.301 |
| 4F管理层 | HP LaserJet Enterprise M507 | 192.168.1.401 |

### 2.3 常见故障排除

- **打印机脱机**：右键打印机图标，取消"脱机使用打印机"
- **打印队列堵塞**：打开"服务"，重启Print Spooler服务
- **卡纸**：打开打印机后盖，沿纸张运行方向轻轻抽出
- **打印模糊**：更换墨盒或执行清洁程序

## 3. 企业邮箱使用指南

### 3.1 邮箱配置

- 邮箱服务器：mail.company.com
- IMAP端口：993（SSL加密）
- SMTP端口：587（TLS加密）
- 单封邮件大小限制：50MB
- 邮箱总容量：10GB
- 超出容量后将无法接收新邮件

### 3.2 Outlook配置步骤

1. 打开Outlook，选择"文件" → "添加账户"
2. 输入公司邮箱地址
3. 选择"手动设置或其他服务器类型"
4. 选择IMAP
5. 收件服务器：mail.company.com，端口993，加密方式SSL
6. 发件服务器：mail.company.com，端口587，加密方式TLS
7. 输入域账号密码
8. 点击"测试账户设置"验证

### 3.3 邮件安全规范

- 禁止将公司邮件转发到个人邮箱
- 含有敏感信息的邮件必须加密发送
- 邮件附件如为可执行文件(.exe/.bat/.ps1)，将被邮件网关拦截
- 误删邮件可在30天内从"已删除邮件"文件夹恢复

## 5. 网络安全规范

### 5.1 密码策略

- 密码长度最少8位，必须包含大小写字母、数字和特殊字符
- 密码每90天必须更换，不得与最近5次密码相同
- 禁止使用生日、姓名拼音、连续数字作为密码
- 建议使用公司提供的密码管理器1Password生成和存储密码

### 5.2 多因素认证(MFA)

- 所有员工必须启用MFA，支持以下验证方式：
  - 企业微信验证码（推荐）
  - 短信验证码
  - 硬件安全密钥（YubiKey，IT部门统一配发）
- MFA丢失或无法使用时，需携带工牌到IT服务台现场重置

### 5.3 数据分类与保护

| 数据级别 | 标识 | 处理要求 |
|---------|------|---------|
| 公开 | 🟢 绿色 | 可对外分享 |
| 内部 | 🟡 黄色 | 仅公司内部使用 |
| 机密 | 🔴 红色 | 需加密存储和传输，访问需审批 |
| 绝密 | ⚫ 黑色 | 仅限特定人员，禁止复制和打印 |

### 5.4 安全事件报告

发现以下情况需立即报告安全团队(security@company.com)：
- 收到可疑钓鱼邮件
- 电脑出现异常弹窗或运行缓慢
- U盘等外接设备丢失
- 怀疑账号被盗用
- 安全事件响应时间：工作日30分钟内，非工作日2小时内
