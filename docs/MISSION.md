# MISSION — 吃透 supply-chain-qa 面试手册

## 为什么学（Mission）
用户 sss208 目标是 **AI 应用工程师 / Agent 开发工程师** 岗位，求职地域限广东（东莞/深圳/佛山优先，广深佛可接受）。
当前核心任务：准备技术面试，需要
1. 快速、扎实地掌握 `INTERVIEW_STUDY_GUIDE.html`（项目原理 + 面试话术 + 诚实边界）。
2. 被连环追问时不崩——每条链路能落到 **代码行号 + tradeoff + 诚实局限**。
3. 把手册里 "按你实际经验填入" 的 `[TODO]` 占位（section 12 横向能力 / section 13 NL2SQL）替换成自己的真实项目证据。

## 成功标准
- 能脱稿答 73 题自测中 **35+ 题**（手册自身验收线）。
- RRF(K=90 ablation) / 在线护栏 / 三级路由 / NL2SQL 自纠正 这 4 个高频深挖点能讲 2 分钟不卡。
- 诚实短板（见 NOTES）能**主动、自然**说出来，而不是被戳穿。

## 教练方式
- **模拟面试官**：抽题 → 用户口述 → 我给反馈 + 继续追问（追问链）。
- 每个模块练到 "一句话 TL;DR + Why + How + Tradeoff + 诚实局限" 五段齐。
- 优先级：DeepSeek Agent 岗真题映射 ★ → 晓多面经 12 题 → 十三大模块 → 73 题自测。

## 范围边界
- 不替用户编造项目经历；没做过的，按手册话术诚实说 "没做过 + 学习计划"。
- 手册是 **个人项目 demo** 视角，企业级（K8s/CI-CD/多租户）一律按 "诚实差距 + roadmap" 讲。
