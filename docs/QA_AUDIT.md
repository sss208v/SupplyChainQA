## 0. Schema 定义回顾

每条 Q&A 应满足:
- `data-qa-id="QN"` 必填 ✓
- `data-cat="..."` 必填 ✓
- `.qa-meta` 内 3 个 `<span>`:
  - `meta-tag cat` 分类
  - `meta-tag trap` 面试陷阱
  - `meta-tag limit` 诚实局限
  - `meta-tag ref` 代码引用(可选)

> 浏览器启动时 `validateQASchema()` 会给缺字段的 Q&A 标 ⚠️

## 5. 已知限制

1. **"trap" 字段主观性强**: 大多数 Q&A 的"陷阱"已隐含在"诚实版"标记中,显式抽出来可能重复
2. **"ref" 字段是可选的**: 没有显式 code ref 的 Q&A(纯叙述题如 Q33)可以留空
3. **"limit" 字段与答案正文冗余**: 把答案中的"诚实承认"原样复制到 meta 即可,无需改写
4. **晓多面经 Q31-Q40 是 STAR 风格**: 不需要 trap/limit(不是项目问题,是面试通识题)
