## 一、评分维度与权重

供应商绩效评估采用百分制，四大维度及权重如下：

| 维度 | 权重 | 评估周期 | 数据来源 |
|------|------|----------|----------|
| 质量 | 40% | 月度汇总 | IQC检验记录、客诉追溯 |
| 交期 | 30% | 月度汇总 | ERP入库记录 |
| 价格 | 20% | 季度评估 | 采购价格数据库 |
| 服务 | 10% | 季度评估 | 采购员评分+技术响应记录 |

## 二、各维度评分标准（5分制）

### 2.1 质量评分（权重40%）

| 分值 | 标准 |
|------|------|
| 5分 | 来料合格率≥99.5%，零客诉 |
| 4分 | 来料合格率98%-99.4%，客诉≤1次/季度 |
| 3分 | 来料合格率95%-97.9%，客诉≤2次/季度 |
| 2分 | 来料合格率90%-94.9%，客诉≤3次/季度 |
| 1分 | 来料合格率<90%，或发生重大质量事故 |

### 2.2 交期评分（权重30%）

| 分值 | 标准 |
|------|------|
| 5分 | 准时交付率≥98% |
| 4分 | 准时交付率95%-97% |
| 3分 | 准时交付率90%-94% |
| 2分 | 准时交付率80%-89% |
| 1分 | 准时交付率<80% |

### 2.3 价格评分（权重20%）

| 分值 | 标准 |
|------|------|
| 5分 | 报价低于市场均价≥10% |
| 4分 | 报价低于市场均价5%-9% |
| 3分 | 报价等于市场均价±4% |
| 2分 | 报价高于市场均价5%-10% |
| 1分 | 报价高于市场均价>10% |

### 2.4 服务评分（权重10%）

| 分值 | 标准 |
|------|------|
| 5分 | 24小时内响应，主动提供技术支持，配合度极高 |
| 4分 | 48小时内响应，能配合紧急需求 |
| 3分 | 72小时内响应，基本满足要求 |
| 2分 | 响应缓慢，多次催促，配合度差 |
| 1分 | 拒绝配合或多次失联 |

## 三、ABCD等级划分

**综合得分 = 质量得分×40% + 交期得分×30% + 价格得分×20% + 服务得分×10%**

| 等级 | 综合得分 | 供应商占比 | 管理策略 |
|------|----------|-----------|----------|
| A级（优秀） | ≥4.5分 | 约10%-15% | 优先分配订单，免检物料优先考虑，优先付款 |
| B级（良好） | 3.5-4.4分 | 约50%-60% | 正常合作，持续改进 |
| C级（合格） | 2.5-3.4分 | 约20%-25% | 限期整改（90天），减少订单比例 |
| D级（不合格） | <2.5分 | 约5%-10% | 启动淘汰程序，6个月内完成切换 |

## 四、奖惩机制

### 4.1 奖励措施
- **A级供应商**：年度采购份额提升10%-20%；优先参与新品开发；年度表彰大会授予"优秀供应商"称号
- **连续3年A级**：签订3年战略合作协议，享受预付款比例提升至50%

### 4.2 惩罚措施
- **C级供应商**：发出书面整改通知，90天内未改善降为D级
- **D级供应商**：暂停新订单，现有订单逐步转移；情节严重者列入黑名单，3年内不得重新准入
- **重大事故**：发生重大质量事故或交付中断造成损失≥10万元的，直接列入黑名单并追究赔偿责任

### 4.3 评估结果应用
- 评估结果于每季度末15日内公布
- 供应商对评估结果有异议的，可在公布后10个工作日内提出申诉
- 采购部根据评估结果在ERP系统中更新供应商等级，系统自动控制订单分配比例

## 五、评估周期与流程概述

### 5.1 评估周期

供应商绩效评估每季度进行一次，年度进行综合评定。

- **季度评估**：每季度末进行，主要评估质量合格率和交期准时率
- **年度综合评定**：每年12月进行，增加价格竞争力和服务响应评估
- 评估结果于每季度末15日内公布
- 供应商对评估结果有异议的，可在公布后10个工作日内提出申诉

### 5.2 评估维度与权重总览

综合得分 = 质量得分×40% + 交期得分×30% + 价格得分×20% + 服务得分×10%
